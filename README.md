# Recurrent Neural Network (RNN) – Practical Implementation

## 📌 Project Description

This repository contains hands-on practice and experiments with **Recurrent Neural Networks (RNNs)** using Python. It focuses on understanding how RNNs process sequential data, maintain information through hidden states, and learn patterns from time-series sequences.

The notebook covers RNN implementation from basic concepts to advanced experiments, including custom RNN implementation, model training, sequence processing, and comparison of different recurrent architectures.

## 🎯 Objectives

- Understand the fundamentals of Recurrent Neural Networks.
- Learn how sequential data is represented and processed.
- Understand time steps, hidden states, weights, and biases.
- Implement a Simple RNN using NumPy.
- Build and train RNN models using TensorFlow and PyTorch.
- Explore the differences between RNN, LSTM, and GRU.
- Understand vanishing and exploding gradient problems.
- Experiment with gradient clipping.
